# Verify Feature Rule

## Input

- The target rule and scenarios plus service, route, UI, and client-integration deliverables.

## Process

1. Verify each scenario through its data source, service, route prop, UI mode, and interaction boundary.
2. Check limits, empty states, routes, server/client boundaries, named-operation direct imports, and mock/production parity.
3. Report missing behavior as a rule or implementation gap without silently extending scope.

## Output

- Verification evidence for every scenario and a concise coverage, drift, and gap report.
