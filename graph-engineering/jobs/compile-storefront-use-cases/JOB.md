# Compile Storefront Use Cases

## Objective

Compile the latest outputs generated by `analyze-journey-use-cases` into a single application use case document.

## Inputs

This job does not require manual user input. The script discovers and uses the outputs generated by `analyze-journey-use-cases` automatically by the script.

## Process

1. The agent MUST execute:

```bash
node scripts/custom/compile-application-use-cases.mjs <output-path>
```

The agent MUST have resolved the `output-path` before executing this job.

## Output

The output is a concatenation of the latest `analyze-journey-use-cases` output found for each run.

Example:

```md
# user-page

[Latest analyze-journey-use-cases output]

# role-page

[Latest analyze-journey-use-cases output]

# account-page

[Latest analyze-journey-use-cases output]
```

Formatting and output writing are handled automatically by the script.
