# Compile Storefront Use Cases

## Objective

The job MUST compile the latest outputs generated by `analyze-journey-use-cases` into a single application use case document.

The job MUST expose the resolved journey identifiers through structured standard output for downstream jobs.

## Inputs

This job does not require manual user input.

The custom script discovers and uses the latest outputs generated by `analyze-journey-use-cases`.

## Process

The agent MUST execute:

```bash
node scripts/custom/compile-application-use-cases.mjs <output-path>
```

The agent MUST resolve `output-path` before executing this job.

The agent MUST capture the JSON object printed by the script to standard output.

The agent MUST NOT open or inspect the generated output artifact to derive journey identifiers for another job.

## Output

The managed output artifact is a concatenation of the latest `analyze-journey-use-cases` output found for each run.

Example:

```md
# user-page

[Latest analyze-journey-use-cases output]

# role-page

[Latest analyze-journey-use-cases output]

# account-journey

[Latest analyze-journey-use-cases output]
```

Formatting and artifact writing are handled automatically by the script.

The script MUST print exactly one JSON object to standard output after successfully writing the artifact:

```json
{
  "outputPath": "/absolute/path/to/OUTPUT-YYYYMMDD-HHMM.md",
  "journeys": ["account", "role", "user"]
}
```

Journey identifiers MUST be derived from source run names by removing a final `-journey` or `-page` suffix.

The `journeys` array is the supported handoff for downstream jobs. The artifact content is not a downstream input interface.

When execution fails, the script MUST print the reason to standard error and exit with a non-zero status code.
