# test-job-agent-heavy

## Objective

The job MUST generate a country report from the required country input.

## Inputs

The job MUST receive:

- A country name.
- A domain.

## Process

1. The agent MUST create a report for the requested country with the information it already holds in memory, without using tools, for the following topics.

- Capital:
- Population:
- Currency:
- Description:

## Output

The job MUST produce a Managed Output as a Markdown document generated by the agent and written to disk.

Output generation, serialization, and formatting are executed manually by the agent.

**Markdown Document Output**

```md
# Dummy Country Report: <country>

## Data

- Capital: <dummy value>
- Population: <dummy value>
- Currency: <dummy value>
- Description: <dummy value>
```

**Context Output Extension**

In addition to the mandatory artifact links, the Context Output MUST report:

- The country requested by the user.
- Whether the country had to be requested because it was missing.
- That the report contains dummy data generated by the agent.
- That the generated report was written to disk.

On successful completion, the agent MUST report the generated artifact path.

On failure, the agent MUST report that the country input is missing or that the target path could not be written.
