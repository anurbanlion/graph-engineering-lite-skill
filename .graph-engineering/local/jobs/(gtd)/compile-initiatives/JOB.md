# Compile Initiatives

## Objective

The job MUST compile an initiative index from the latest managed outputs produced by a configurable source job across all run domains.

The job MUST NOT modify source managed outputs or assume a fixed destination domain or source job identifier.

## Inputs

The job MUST receive:

- `domain`: a kebab-case domain where the compiled initiative MUST be stored;
- `source-job-identifier`; a kebab-case job name whose managed outputs define initiative candidates.

Examples:

```txt
domain: global
source-job-identifier: create-initiatives
```

## Scope

The agent MUST inspect:

```txt
.graph-engineering/runs
```

The agent MAY modify:

```txt
.graph-engineering/runs/<domain>/compile-initiatives/OUTPUT-*.md
```

The agent MUST NOT modify source managed outputs.

## Process

**1. Discover Latest Outputs**

1. The agent MUST execute the `get-latest-output-by-job` script with the provided `job-identifier`.

Example:

```bash
node <local-skill-folder>/graph-engineering/scripts/get-latest-output-by-job.mjs --job <job-identifier>
```

Example output (list of relative paths):

```txt
.graph-engineering/runs/chikiarena/create-initiative/OUTPUT-20260819-0601.md
.graph-engineering/runs/youtube/create-initiative/OUTPUT-20260818-1200.md
```

**1. Resolve output path**

1. The agent MUST execute the `resolve_output_path` script to obtain the <output-path>.

Example:

```bash
python3 resolve_output_path.py <domain> compile-initiatives
```

Example output (list of relative paths):

```txt
.graph-engineering/runs/<domain>/compile-initiatives/OUTPUT-20260819-0601.md
```

**3. Compile Initiatives**

1. The agent MUST execute the custom `compile-initiatives` script passing the discovered relative paths so the script generates the compiled Markdown artifact.

Example:

```bash
node <local-skill-folder>/graph-engineering/scripts/custom/compile-initiatives.mjs --domain <domain> --paths ".graph-engineering/runs/chiquiarena/create-initiatives/OUTPUT-20260819-0601.md" ".graph-engineering/runs/youtube/create-initiatives/OUTPUT-20260818-1200.md" --output <output-path>
```

## Scripts

**Script Pseudocode: Generic `get-latest-output-by-job`**

```text
INPUT job_identifier

SET runs_root = ".graph-engineering/runs"

FOR EACH domain directory under runs_root
  IF domain contains job_identifier directory
    FIND OUTPUT-*.md files in that directory
    IF no output exists
      LOG warning: directory exists for domain but contains no OUTPUT-*.md files
    ELSE
      SELECT latest output by timestamp
      ADD discovered output path to output path list
    END IF
  END IF
END FOR

RETURN output path list
```

**Script Pseudocode: Custom `compile-initiatives`**

```text
INPUT domain
INPUT output_path
INPUT relative_paths list from get-latest-output-by-job

FOR EACH path IN relative_paths
  READ file at path
  IF YAML frontmatter is missing or invalid
    ADD skipped result with reason
  ELSE
    EXTRACT initiative title and description from frontmatter
    ADD initiative to included results
  END IF
END FOR

BUILD Markdown output with frontmatter, Included, and Skipped sections
WRITE Markdown artifact to output_path
RETURN compiled Markdown and structured counts and output metadata
```

## Output

Managed Output is generated by the script.

**Markdown Document Output**

```md
---
source_job_identifier: <source-job-identifier>
included_count: <number>
skipped_count: <number>
---

# Compiled Initiatives

| --- | --- | --- | --- |

## Skipped

| Domain | Source | Reason |
| --- | --- | --- |
| <source-domain> | <latest-output-path> | <reason> |
```
