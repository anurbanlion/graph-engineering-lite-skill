# Worker Memory Template

Use this structure for `MEMORY.md`. Write in English unless the user explicitly requests another language.

```markdown
# Worker <number> — <Responsibility>

## Durable Responsibility
<!-- What this worker owns and its completion boundary. -->

## Reusable Guidance
<!-- Corrections, rules, patterns, commands, and useful sources. -->

## Inputs and Outputs
<!-- Durable dependency inputs and deliverables for this worker. -->
```

Memory MAY record durable lessons, commands, snippets, Jobs, and consulted documents. It MUST NOT become a historical execution report or list work that is complete, incomplete, or not applicable.
