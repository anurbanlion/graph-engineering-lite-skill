## Jobs Summary

## `create-job`
* **Objective:** Generate or refactor job definition files.
* **Input:** Description of requirements or legacy job draft/file.
* **Output:** Markdown document and optional scripts for the new job.

---

## `analyze-journey-use-cases`
* **Objective:** Classify UI use cases in pages and shells, and map existing vs. expected implementations.
* **Input:** Domain name, page and shell files or code, screenshots or UI flow description.
* **Output:** Markdown document with tables of expected (`🎯`), existing (`🔎`), and excluded use cases.

---

## `compile-storefront-use-cases`
* **Objective:** Unify into a single document the latest analysis results generated by `analyze-journey-use-cases`.
* **Input:** No manual input required (automatic discovery of the latest analyses).
* **Output:** Markdown document with all use case tables.

---

## `compile-storefront-journeys`
* **Objective:** Compile and identify existing journeys in the application from the runs directory.
* **Input:** Domain name (defaults to `global-designs`).
* **Output:** Markdown document with a simple list of all journeys.

---

## `scaffold-journey-architecture`
* **Objective:** Generate the base directory and file structure (Domain, Application, Infrastructure) for one or more journeys.
* **Input:** One or more journey identifiers.
* **Output:** Code files created at `apps/storefront/apis/[journey]/...`.

---

## `define-journey-use-case-dtos`
* **Objective:** Explore the repositories, illustrate data flow between Storefront, packages, Medusa and Supabase, and define backend response DTOs.
* **Input:** A journey, use case(s) and optionally previous Mermaid diagram context.
* **Output:** Markdown document with a Mermaid diagram and a code file (`[journey].contract.ts`).

---

## `implement-services`
* **Objective:** Implement real and mock service functions for a Storefront journey based on contract analysis.
* **Input:** A journey identifier and service use cases to implement.
* **Output:** Code files created at `apps/storefront/apis/[journey]/infrastructure/services/...`.

---

## `implement-repository-and-use-cases`
* **Objective:** Implement real repository, mock repository, repository factory, and application use cases for a Storefront journey.
* **Input:** A journey identifier and use cases to implement.
* **Output:** Code files created at `apps/storefront/apis/[journey]/infrastructure/repository/...` and `apps/storefront/apis/[journey]/application/use-cases/...`.

---

## `add-tasks`
* **Objective:** Transform free-form initiative ideas into a Markdown task list with actionable tasks, execution responsibility, and duration estimates.
* **Input:** A kebab-case domain identifier and source context with task ideas/notes (optionally existing tasks).
* **Output:** Markdown task artifact managed output (task list, optional References and Transformation pointers).
